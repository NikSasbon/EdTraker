# Itinerario náutico: Guardería Laura (Tigre) → Isla Martín García

Este paquete contiene una derrota **orientativa** para imprimir y cargar puntos en un GPSMAP Garmin 400/500:

- `itinerario_guarderia_laura_isla_martin_garcia.pdf`: PDF de 6 hojas con mapas esquemáticos por tramo y una hoja de carga manual.
- `waypoints_garmin_400_500.csv`: listado completo de waypoints en formato `hddd° mm.mmm'`, decimal WGS84, descripción y datos de interés.
- `waypoints_garmin_400_500.gpx`: archivo GPX con los waypoints y la ruta.
- `generate_itinerary.py`: script reproducible que genera el PDF, el CSV y el GPX.

## Advertencia de seguridad

El material es para planificación previa y orientación general. **No reemplaza** cartas oficiales SHN, Avisos a los Navegantes, Prefectura, balizamiento vigente, consulta de mareas/altura de agua, pronóstico meteorológico, ni el uso de sonda y criterio marinero. El punto `LAURA` es aproximado y debe confirmarse al botar la lancha.

- SHN: cartas H118, H115, H116 y H117 indicadas por CVPB como cartografía de referencia para validación final.
